Two Wasm modules, one browser

The static website serves a compiler built to Wasm. It compiles Atto source into a second Wasm module and executes that generated module inside a disposable worker with restricted host imports and execution deadlines.

Scope: The browser playground currently supports a subset with functions, recursion, checked 64-bit integers, booleans, control flow and standard output. Actor examples also exercise browser Workers, but these demonstrations are not a guarantee of native backend parity. The canonical compiler contract describes the implemented guest subset.

Local saved drafts remain in this browser unless you explicitly export or share them. The generated Wasm can be downloaded for inspection.

AttoLang is under active development. The playground is a subset preview, not evidence of production runtime or backend parity.
