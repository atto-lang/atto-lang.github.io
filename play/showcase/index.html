REAL RUST COMPILER · REAL WASM GUESTS

Code that actually runs.

These 40 language programs compile with the exact SHA-pinned Atto Rust/Wasm browser compiler. Choose Compile & execute to load the unchanged Atto source and run the generated guest WebAssembly in a disposable Worker. The output shown here is the expected test oracle, not a prerecorded execution.

This showcase is limited to the pinned browser compiler. It does not establish Java, LLVM, .NET or other backend parity. Unsupported design previews remain separately labeled in the playground and never generate a fake guest.
