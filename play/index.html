Real compiler. Explicit scope.

The playground compiles a subset of AttoLang, not the full language. It supports functions, recursion, int (checked 64-bit) and bool, val/const/let bindings, if … then … fi, while … do … done, for, loop, and stdio.println. Syntax follows the reference compiler. Classes, actors, strings as values, floats, match and imports are not lowered yet and produce compiler errors. A failed compilation never produces a guest Wasm artifact.
