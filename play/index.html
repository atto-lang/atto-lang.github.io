Real compiler. Explicit scope.
The playground compiles a subset of AttoLang, not the full language. It supports functions, recursion, int (checked 64-bit) and bool, val/const/let bindings, if … then … fi, while … do … done, for, loop, and stdio.println. Syntax follows the reference compiler. Advanced syntax in the preview dropdown (including generators, tasks, is, using, pipelines, and supervisors) is illustrative and not yet lowered by this pinned browser compiler. Preview code is never evaluated as JavaScript. A failed compilation never produces a guest Wasm artifact.
