WebAssembly playground · experimental M0

Compile Atto locally.

The browser downloads the compiler as WebAssembly. Your source is compiled locally into a second WebAssembly module and run in an isolated, disposable worker. No compilation server is required.

Open experimental playground

The link above is the planned GitHub Pages project URL. The editor will be available there only after the playground PR, Pages deployment and public URL have been verified. This page is not evidence of a live deployment.

Current support

One fnc main() -> int, integer arithmetic, local bindings and return. Unsupported syntax fails compilation instead of pretending to offer the full language.

Source and implementation: atto-lang/atto-playground
