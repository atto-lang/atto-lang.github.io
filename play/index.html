Real compiler. Explicit scope.
The executable examples use the pinned Rust/Wasm subset compiler. The separate Syntax previews group shows proposed AttoLang features (including trap, Result/Option, channels and Rx) that this compiler cannot run yet. Preview samples have Run disabled until edited; they never generate Wasm merely by selection. See the compiler contract for current lowering and preview caveats. A failed compilation never yields a guest Wasm artifact.
