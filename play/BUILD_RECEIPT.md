# AttoLang public playground asset receipt

The browser UI and runtime shipped by this website's `/play/` route are synchronized with `atto-lang/atto-playground` `main` at exact commit `75d1eca52301237b73bbf79e8465922fe7b1505a` (merge of atto-playground#26). The previously mirrored runtime is now evolving through a separately reviewed tenant VM branch; do not assume these files are still byte-identical to that commit. The proposed browser TenantVM runs main and all spawned actors in one page-owned runner Worker, with a private Wasm instance per actor and bounded mailboxes. This is not part of the currently deployed release until review, executed CI and protected Pages dispatch.

The compiler artifact is `play/public/atto_compiler.wasm`, SHA-256 `b7c5e86d8b25a67cc1ea3200b08e088c4022b9d9f8599ba7b87b1253f6822860` (253921 bytes). It was built from `atto-lang/atto-source.rs` head `865c835c7f343a2bb00b5b73a6010825f57be794` (merged as atto-source.rs#29) and tree `6520a246849366dfdeb77eaba24956f56dc18713`, with rustc 1.85.1 for wasm32-unknown-unknown. The hosted CI run of that head rebuilt the same digest byte for byte. Compiler provenance is in `play/public/atto_compiler.receipt.json`, and the browser worker checks the digest against `play/src/compiler-pin.js`.

The release staging allowlist (`.github/scripts/package-playground.mjs`) includes the tenant-local actor host and runner Worker scripts (not the obsolete actor-worker asset) and the three new examples. Source tests include the actor host unit tests and Chromium E2E for classes, enums and actors in one real browser TenantVM Worker; the website's release workflow additionally retests the staged `/play/` files. Treat test results as verified only when an exact commit has nonzero executed job steps and successful outcomes.

This public mirror contains static browser assets and examples, not compiler source, backend services or secrets. The compiler supports only the documented language subset, not full AttoLang. Successful repository tests do not prove Firefox/WebKit parity.

**Security:** `play/public/atto_compiler.wasm` is in a *public* GitHub repository, and this site is served by GitHub Pages directly from `main`, so merging this change publishes it.
