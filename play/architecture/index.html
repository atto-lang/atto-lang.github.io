⊘
Wasmtime cannot be embedded as the browser's native Wasm engine.

Browser hosts instantiate Wasm using WebAssembly.compile/instantiate inside a page or Web Worker. Wasmtime is appropriate for supported native/server embeddings; Node can also use V8's native WebAssembly APIs. Browser Workers are not OS sandboxes.
