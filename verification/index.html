05 / TRUST BOUNDARIES
Verification protocol
What the dashboard can prove — and what it refuses to infer.
01
Exact-tree identity
PR head, checked head, CI run head, commit tree and mirror tree must agree. A green job from an old head is invalid.
02
Real guest execution
Parser acceptance and host harness success are distinct from guest-executed conformance. Neither upgrades to execution parity.
03
Fresh provenance
Evidence expires after 72 hours by default. Missing artifact digests, runner identity, receipts, or upstream verification block acceptance.
04
Independent authority
Approval must come from someone other than the PR author, on the exact head. Final release certification remains an external signed decision.
⌑ The site never checks out source, never changes a repository, never triggers CI, and never merges code. Optional GitHub checks use read-only public metadata endpoints. Imported claims are untrusted until independently corroborated.
